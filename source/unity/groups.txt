# Unity groups that are not simply "one per directory".  Hand-written; read by
# scripts/gen_unity.py, which generates the rest of source/unity/ from it.
#
# Every library source joins the group of its directory (source/opt/flat/cfg/*.c
# -> opt_flat_cfg), unless a line below claims it first.  Lines are
#     group: pattern [pattern ...]
# with shell globs relative to source/; the first line that matches a source
# wins.  A directory too big for one TU (the device compiles each group in
# a few MB of heap) is cut here into named pieces; its remaining files keep the
# directory's own group.  A source the rules keep apart (see gen_unity.py)
# builds as its own TU wherever it is listed, and members that do not use
# USING_GLOBALS (state through s1->, not tcc_state->) cannot share a TU with
# those that do: they get the group's name plus "_s1".
